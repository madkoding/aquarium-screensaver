Qué incluye

Creado desde cero con Python y OpenGL.

Un mundo continuo en todos los monitores

Los peces nadan de una pantalla a la siguiente. Funciona con tamaños y orientaciones mezclados.

Ocho especies de peces procedurales

Tetras neón, peces payaso, cirujanos azules, escalares, discos, peces león, atún y un tiburón. Forman cardúmenes y huyen del tiburón.

Iluminación con trazado de rayos

Sombras suaves, oclusión ambiental, cáusticas de una superficie en movimiento, haces de luz y una superficie del agua que actúa como espejo vista desde abajo.

Un arrecife detallado

Corales ramificados y de mesa, abanicos de mar, anémonas, bosques de algas, guijarros, medusas, burbujas y nieve marina.

Día, atardecer y noche

La luz sigue tu reloj. De noche los tetras neón brillan.

Rápido y ajustable

Sincronizado con la frecuencia de tus monitores, escalado AMD FSR opcional y una ventana de ajustes con calidad, cantidad de peces, iluminación y más.

Descarga e instalación

Toma alrededor de un minuto. Sin instalador ni cuenta.

  1. Descarga Aquarium.scr

    Pulsa el botón de arriba, o búscalo en la página de la última versión (el archivo está en Assets).

  2. Haz clic derecho sobre el archivo y elige Instalar

    Windows abre la ventana Configuración del protector de pantalla con él ya seleccionado. Si Windows pide permisos de administrador, acéptalos: copia el archivo donde viven los protectores de pantalla.

  3. Pulsa Aplicar y Aceptar

    En Esperar elige cuántos minutos de inactividad quieres. Usa Vista previa para probarlo al instante; cualquier tecla o movimiento del ratón lo cierra.

  4. Opcional: pulsa Configuración… para ajustarlo

    Color del agua, calidad, cantidad de peces, iluminación (automática según tu reloj), profundidad de campo, trazado de rayos y escalado AMD FSR. Los valores por defecto ya se ven bien y van fluidos.

¿Windows dice «protegió su PC»? El archivo no está firmado digitalmente (hace falta un certificado de pago), así que SmartScreen o tu antivirus pueden avisar, como con muchas herramientas pequeñas. Pulsa Más información → Ejecutar de todas formas. Si el menú del clic derecho no tiene Instalar, haz clic derecho → Propiedades → marca Desbloquear → Aceptar primero. Puedes leer todo el código en GitHub y compilarlo tú mismo.
¿No encuentras la ventana del protector de pantalla?

Pulsa la tecla Windows y escribe protector de pantalla, y abre Cambiar protector de pantalla. En Windows 11 también está en Configuración → Personalización → Pantalla de bloqueo → Protector de pantalla. Elige Aquarium Screensaver en la lista desplegable.

Instalar a mano (copiar el archivo)

Copia Aquarium.scr a C:\Windows\System32 (requiere permisos de administrador). Aparecerá en la lista de protectores de pantalla.

Ejecutarlo desde el código 
git clone https://github.com/madkoding/aquarium-screensaver.git
cd aquarium-screensaver
python -m pip install -r requirements.txt
python aquarium_saver.py /s

Necesitas Python 3.10+ en Windows. Para compilar tu propio Aquarium.scr ejecuta .\build.ps1 (mira el README).

Desinstalar

Abre otra vez la ventana del protector de pantalla y elige otro (o (Ninguno)). Para borrar el archivo, elimina Aquarium.scr de la carpeta donde lo copiaste (normalmente C:\Windows\System32). Tus ajustes están en %APPDATA%\AquariumScreensaver; borra esa carpeta para restablecerlos.
